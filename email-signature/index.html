Email signature

Edit the fields, hit Copy signature, then paste it into your mail app's signature settings.

Gmail
  1. Settings (gear) → See all settings → General → Signature → Create new.
  2. Click in the box and paste (⌘V / Ctrl+V).
  3. Set it as the default for new emails and replies, then Save changes at the bottom.
Outlook (web / new Outlook)
  1. Settings → Account → Signatures → New signature.
  2. Paste into the editor, pick it as the default, Save.
Apple Mail (Mac)
  1. Mail → Settings → Signatures → +.
  2. Uncheck “Always match my default message font”, then paste into the right-hand box.
iPhone Mail
  1. Email this page's signature to yourself from the Mac/Gmail, open it on the iPhone and copy it.
  2. Settings → Apps → Mail → Signature → paste, then shake to undo if iOS strips the styling and choose “Undo Change Attributes”.
